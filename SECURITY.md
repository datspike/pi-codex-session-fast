# Security

Do not submit keys, tokens, `auth.json` contents, session JSONL, or other secrets in issues, pull requests, or CI logs.

If you find a vulnerability, do not disclose it publicly before it is fixed. Contact the repository owner through a private channel and include the smallest reproducible description you can provide.

The extension does not own auth or transport, does not store Fast on disk, and does not store request or response text in its metadata receipts.
